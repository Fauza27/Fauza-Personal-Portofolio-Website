## Model Comparison Results

| Model | MAE | RMSE | RMSE reduction vs ARIMA |
|-------|-----|------|----------|
| ARIMA (5,1,0) | $5,800 | $8,178 | Baseline |
| Linear Regression | $3,726 | $4,792 | **41.4%** |
| Ridge (α=0.1) | $3,676 | $5,049 | 38.3% |

**Trade-off**: Ridge had the lowest MAE; Linear Regression had the lowest RMSE. The choice depends on which error measure matters most for the use case.

**Evaluation limit**: The source covers only 13 weekly observations. With a 90/10 chronological split, the held-out window is very small, so these errors should be treated as an exploratory comparison. Rolling-origin evaluation on a longer history would provide stronger evidence.

## Why Linear Regression Won?

**Data Characteristics**:
- No strong seasonality (ARIMA's strength wasted)
- Short time series (13 weeks, limiting reliable model comparison)
- Clear linear trend (perfect untuk LR)
- Simple model prevents overfitting

**Lesson**: Model complexity ≠ Better performance. Always test simple baselines.

## Technical Challenges Solved

**Short Time Series**: Only 13 weeks of data. This limits parameter estimation and leaves a small holdout. I included simple models as baselines and would collect a longer history before making operational forecasts.

**High Variability**: Daily sales std $1,842. Solution: Weekly aggregation untuk smooth noise.

**Model Selection**: Systematic comparison dengan consistent metrics. Don't assume ARIMA is always best.

**Hyperparameter Tuning**: GridSearchCV dengan cross-validation untuk find optimal Ridge alpha.
